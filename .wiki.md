# Project Summary
The KCROC project is an innovative online platform that simplifies the booking of computer repair services for laptops, desktops, and other devices. It enhances customer experience by allowing users to conveniently schedule repairs, manage bookings, and receive confirmations through WhatsApp. This platform caters to individual consumers and businesses seeking reliable tech support, focusing on quality service and efficiency.

# Project Module Description
- **Backend**: Manages database interactions, user authentication, and service management.
- **Frontend**: Provides the user interface for service booking, showcasing available services, and facilitating user interactions.
- **Service Booking Form**: A component for users to select device types, describe issues, and schedule pickups.
- **Gallery**: Displays images of repair services and components, currently showing a placeholder state after the removal of specific images.

# File Description Inventory
- **app/backend/main.py**: Entry point for the backend service, initializes the application.
- **app/backend/services/service_bookings.py**: Logic for managing service bookings.
- **app/frontend/src/pages/BookingPage.tsx**: The service booking form component.
- **app/frontend/src/pages/Gallery.tsx**: Updated gallery component reflecting a placeholder state.
- **app/frontend/src/App.tsx**: Main application file defining routing.
- **app/frontend/src/components/ui/button.tsx**: UI button component used in forms.
- **app/frontend/src/components/SEOHead.tsx**: Component for setting SEO metadata dynamically.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: Atoms Cloud
- **Deployment**: Vite, pnpm for package management

# Usage
1. **Install Dependencies**:
   - Navigate to the backend directory and run `pip install -r requirements.txt`.
   - Navigate to the frontend directory and run `pnpm install`.
   
2. **Build the Project**:
   - For the backend, run `uvicorn main:app --reload`.
   - For the frontend, run `pnpm run build`.

3. **Run the Project**:
   - Start the backend server to handle API requests.
   - Start the frontend development server to serve the user interface.
