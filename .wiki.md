# Project Summary
The KCROC project is a web application dedicated to providing comprehensive repair services for laptops and MacBooks in Kuwait. It aims to enhance customer satisfaction by offering easy access to a variety of repair services, such as screen and battery replacements, through a streamlined and user-friendly interface. The application is optimized for performance on platforms like Netlify and Vercel, ensuring efficient resource management and a seamless user experience.

# Project Module Description
The project consists of several functional modules:
- **App.tsx**: Main entry point of the application with defined routing.
- **Header.tsx**: Navigation menu component with service dropdown.
- **Gallery.tsx**: Displays images related to repair services.
- **ScreenReplacement.tsx**: Dedicated page for screen replacement services.
- **BatteryReplacement.tsx**: Details battery replacement services.
- **MacBookRepair.tsx**: Page for MacBook repair services.
- **LaptopRepair.tsx**: Page for general laptop repair services.
- **BookingPage.tsx**: Form for scheduling repair pickups.
- **Contact.tsx**: Contact form for customer inquiries.
- **About.tsx**: Information about the company and team.
- **Services.tsx**: Overview of all services offered.
- **NotFound.tsx**: 404 error page for non-existing routes.
- **Pricing.tsx**: Pricing details for services.
- **PrivacySecurity.tsx**: Information on privacy and data security practices.
- **Hero.tsx**: Featured hero section with a background image.
- **GamingPCCooling.tsx**: Page for gaming PC cooling services.
- **Footer.tsx**: Footer component with links to important pages.

# Usage
To set up the project:
1. Install dependencies:
   ```
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run linting to ensure code quality:
   ```
   pnpm run lint
   ```

To deploy on Netlify:
1. Download the entire project using the **Export** feature.
2. Unzip the downloaded file.
3. Navigate to the `app/frontend/` folder.
4. Push it to a Git repo, or drag-and-drop the folder into Netlify's deploy UI.
5. Set the build command to `pnpm install && pnpm run build` and publish directory to `dist`.

Alternatively, you can deploy the pre-built `dist/` folder for a direct drag-and-drop deployment on Netlify.
