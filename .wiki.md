# Project Summary
The KCROC project is a web application that provides repair services for laptops and MacBooks in Kuwait. It enhances customer experience by offering easy access to various repair services, such as screen and battery replacements, through an intuitive interface. The application is optimized for deployment on platforms like Netlify, ensuring a smooth user experience with efficient management of resources.

# Project Module Description
The project consists of several functional modules:
- **App.tsx**: The main entry point of the application where routing is defined.
- **Header.tsx**: Contains the navigation menu for the application, featuring a dropdown for services.
- **Gallery.tsx**: Displays images related to the services offered.
- **ScreenReplacement.tsx**: A dedicated page for screen replacement services.
- **WebDesignKuwait.tsx**: Page detailing web design services.
- **Home.tsx**: New landing page for the application.
- **netlify.toml**: Configuration file for deploying the application on Netlify, ensuring proper dependency installation.

# Usage
To set up the project:
1. Install dependencies:
   ```
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run linting to ensure code quality:
   ```
   pnpm run lint
   ```

To deploy on Netlify:
1. Download the entire project using the **Export** feature.
2. Unzip the downloaded file.
3. Navigate to the `app/frontend/` folder.
4. Push it to a Git repo, or drag-and-drop the folder into Netlify's deploy UI.
5. Set the build command to `pnpm install && pnpm run build` and publish directory to `dist`.

Alternatively, you can deploy the pre-built `dist/` folder for a direct drag-and-drop deployment on Netlify.
